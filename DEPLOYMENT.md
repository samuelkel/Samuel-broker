# Deployment Guide

For a quick visual preview, open `index.html` directly after extracting the ZIP. For public hosting, upload the project to a static host (for example, Netlify, Cloudflare Pages, or GitHub Pages). Because this is a self-contained front end, `index.html` is sufficient for the visual demo.

Do not treat static hosting as production readiness for an investment platform. Before accepting real customers or funds, build and independently review a secure backend, authentication, transaction ledger, compliance workflow and operational controls. Keep demo mode clearly labelled.
